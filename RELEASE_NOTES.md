## Основные изменения

### Ребрендинг
- Новое название: **Eptal-Analyzer**.
- Обновлены название окна, экран загрузки, README, метаданные проекта и сообщения лаунчера.
- В интерфейсе и документации сохранена атрибуция: основано на L0p4Map by HaxL0p4.

### Интерфейс
- Переработана тема в современный тёмно-серый стиль.
- Основной текст сделан белым, заголовки/вторичный текст — чуть темнее.
- Кнопки получили скруглённые углы, более заметную обводку и hover/pressed-эффекты.
- Убраны квадратные скобки из подписей кнопок, текст кнопок сделан жирнее.
- Названия/заголовки секций сделаны тоньше и немного тусклее.
- Улучшена читаемость: тёмный фон консоли вывода в первой вкладке, тёмный фон вкладки «Карта сети», более заметные разделители заголовков таблиц.

### Локализация
- Основные элементы интерфейса переведены на русский: навигация, кнопки, ключевые подписи, часть статусных сообщений, панель топологии, заголовки таблиц.
- Часть служебных/динамических строк ещё может оставаться на английском.

### Улучшения вкладок
- **Карта сети**: возвращён более тёмный фон области графа.
- **Анализ трафика**: левая панель «Устройства» расширена, надпись сделана ярче/жирнее, размеры столбцов настроены для читаемости заголовков.
- **Загрузочный экран**: логотип поднят выше над текстом.

### Запуск и совместимость Windows
- Добавлен `run-l0p4map.bat` для запуска из папки программы.
- Батник запрашивает права администратора через UAC.
- Исправлена проверка привилегий для Windows в `main.py` и `core/scanner.py` (`os.getuid()` → проверка администратора Windows).
- Подготовлено виртуальное окружение и установка зависимостей из `requirements.txt`.

### Зависимости и диагностика
- В `README.md` добавлен раздел про **Npcap**: обязателен для ARP/L2-сканирования в Windows, требуется установка в режиме WinPcap API-compatible.
- Отмечено, что Npcap — драйвер ядра Windows: его нельзя встроить как обычный файл программы; при установщике нужно учитывать лицензию/распространение Npcap.

## Известные ограничения
- Для полного функционала нужны права администратора, Nmap и Npcap.
- Без Npcap сканирование L2/ARP в Windows не работает.
- Часть интерфейсных строк всё ещё не переведена на русский.
- Визуальная тема обновлена массово, возможны точечные недочёты в отдельных панелях.
